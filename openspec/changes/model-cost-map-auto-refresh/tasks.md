- [x] 2.2 В `ProxyConfig._check_and_reload_model_cost_map` (`proxy_server.py`) добавить дефолтный путь: если строки расписания нет или `interval_hours` пуст, а интервал включён, релоад выполняется, когда `now >= model_cost_map_default_refresh_at` (новое поле `ProxyConfig`, один `datetime`, старт = момент создания плюс 60 с). Время сравнивается через `utc_now()` модуля (его подменяют существующие тесты). Любой успешный релоад, включая ревизионный и по расписанию администратора, сдвигает поле на now + интервал, чтобы только что загрузившийся под не фетчил повторно. Ревизионный путь и расписание администратора остаются как были и имеют приоритет. Проверка: юнит-тесты (мок `refetch`): строки нет и срок вышел, фетч идёт; срок не вышел, фетча нет; `MODEL_CATALOG_REFRESH_HOURS=0`, фетча нет; ошибка фетча, повтор не раньше чем через час и карта цела; расписание администратора выигрывает у дефолта.
