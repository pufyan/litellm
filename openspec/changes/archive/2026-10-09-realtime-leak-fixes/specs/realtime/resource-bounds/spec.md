## Purpose

Память realtime-сессии ограничена сверху независимо от длительности звонка. Переполнение накопителя не роняет звонок молча и не течет: лишнее дропается со счетчиком, сессия продолжает работать, владелец объекта всегда известен.

## ADDED Requirements

### Requirement: Границы накопителей сессии
Каждый растущий накопитель сессии имеет кап по количеству и байтам. При превышении дропаются только служебные события, spend-критичные имеют приоритет удержания по решению D7. Безлимитный append запрещен. Реализуется задачами 1.1, 1.2.

#### Scenario: Часовой звонок
- **WHEN** сессия идет час с активным обменом событиями
- **THEN** размеры `messages`, `input_messages`, `tool_calls`, чанков транскрипта остаются в капах, рост RSS плоский

#### Scenario: Обрыв без response.done
- **WHEN** ответ модели оборван и завершающее событие не пришло
- **THEN** чанки оборванного ответа ограничены капом и не растут бесконечно

### Requirement: Границы буфера досылки при reconnect
Преппенд недоставленных сообщений при повторном flush не обходит капы pending-буфера. При превышении дропается хвост по решению D12, порядок головы сохранен. Забор-и-очистка pending атомарна под локом по решению D13. Реализуется задачами 1.3, 2.2.

#### Scenario: Серия неудачных reconnect
- **WHEN** несколько reconnect подряд не доставили буфер
- **THEN** размер pending-буфера не превышает кап, порядок оставшихся кадров сохранен

### Requirement: Bounded-реестр сессий
Реестр shutdown остается на сильных ссылках. Каждая задача насоса снимает регистрацию в done-callback, orphan-сессии подбирает reaper по таймауту с force-close. Дефолт drain 600 с не меняется. Реализуется задачей 2.1.

#### Scenario: Потерянная задача сессии
- **WHEN** задача сессии потеряна до `finally` с `unregister`
- **THEN** done-callback снимает регистрацию, либо reaper подбирает сессию по таймауту с force-close

### Requirement: Детерминированное закрытие сокетов и задач
Каждый сокет, созданный в retry-цикле reconnect, закрывается на всех путях выхода через try/finally на итерацию. Idle-таймаут чтения по умолчанию выключен и срабатывает только на полное молчание дольше max-idle по решению D9. Отмена задач дожидается завершения. Реализуется задачами 2.2, 2.3.

#### Scenario: Reconnect посреди обрыва
- **WHEN** connect удался, а отправка resume упала
- **THEN** промежуточный сокет закрыт, утечки дескрипторов нет

#### Scenario: Молчащий бэкенд
- **WHEN** бэкенд не отвечает дольше таймаута чтения
- **THEN** задача чтения завершается, сессия идет по graceful close, а не висит

### Requirement: Evict в растущих словарях адаптеров
Словари адаптеров, растущие по ключу content-part, имеют evict-политику по решению D10: активные `response_id` защищены, evict по terminal-событию, LRU-кап только backstop. Бесконечный рост по ключам запрещен. Реализуется задачей 3.1.

#### Scenario: Долгая xAI-сессия
- **WHEN** сессия обработала тысячи content-part
- **THEN** размер `_content_part_by_key` ограничен, старые ключи вытеснены

### Requirement: Границы Chirp-бэкенда
Rotaция стримов и очередь Chirp-бэкенда ограничены по решению D11: продюсер использует `put_nowait` с дропом и счетчиком, `close()` пробуждает ждущих, закрытые стримы не копятся в кортеже turn. Реализуется задачей 3.2.

#### Scenario: Стрим без границ turn
- **WHEN** стрим идет долго без завершения turn
- **THEN** число удерживаемых `_RecognizeStream` ограничено, очереди не блокируются навсегда

### Requirement: Границы Bedrock-моста
Журнал `logged` Bedrock-моста ограничен капом по количеству и байтам, циклы `_forward_*` имеют таймауты. Реализуется задачей 3.3.

#### Scenario: Висящий прием Bedrock
- **WHEN** bedrock-стрим перестал отдавать кадры
- **THEN** цикл приема завершается по таймауту, журнал ограничен капом

### Requirement: Наблюдаемость утечек
Размеры накопителей и счетчики дропов видны в debug-логе сессии. Долгий звонок можно прогнать под `tracemalloc` по documented процедуре. Реализуется задачами 1.4, 2.4, 3.4.

#### Scenario: Staging-звонок 30 минут
- **WHEN** звонок идет 30 минут под наблюдением
- **THEN** оператор видит плоские кривые размеров накопителей и нулевые необъясненные дропы
